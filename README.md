# 🖼️ Digital Image Processing

Welcome to my **Digital Image Processing (DIP)** repository!  
This is a self-learning project where I follow tutorials and document my practical exercises using **Python** in **Google Colab**. The focus is on building a solid understanding of how image processing techniques work in real-world applications.

---

## 📚 Learning Objectives

- Understand the fundamentals of digital image processing
- Learn and apply concepts using Python libraries such as OpenCV, NumPy, and Matplotlib
- Perform hands-on implementations of various techniques on real images
- Document the learning process and build a reference for future projects

---

## 🛠️ Tools & Technologies

| Tool               | Purpose                           |
|--------------------|-----------------------------------|
| Python             | Programming language              |
| Google Colab       | Interactive coding notebooks      |
| OpenCV             | Image processing operations       |
| NumPy              | Numerical operations              |
| Matplotlib         | Visualization of image data       |
